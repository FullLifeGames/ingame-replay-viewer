# Our own codebase; showdown-bw2 is only a reference

LuciPengu/showdown-bw2 (GPL-3.0, October 2026) already renders Showdown battles in Black 2: replays, spectated battles, and live play through BW2's own menus. Its design is built around BW2 alone, though. This project needs several target games behind one game-neutral battle script (ADR 0004), and a hosted public tool, so it is its own codebase under MIT.

showdown-bw2 is read to learn how BW2 behaves and where its internals are. Its code is not copied.
